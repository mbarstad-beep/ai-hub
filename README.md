# 📖 Sobre

O LocalAI Hub é um sistema criado para transformar o gerenciamento de IAs locais em uma experiência simples, moderna e profissional.

Em vez de utilizar várias ferramentas separadas, o objetivo é disponibilizar uma central única para:

- Modelos locais
- MCPs
- Extensões
- Projetos
- Instalação automática
- Dashboard de monitoramento
- Ferramentas para desenvolvedores

Tudo executado localmente no computador do usuário.

# 🔧 Requisitos

- Windows 10
- Windows 11
- PowerShell 5.1+
- 8 GB de RAM (mínimo)
- 16 GB de RAM (recomendado)

# ▶️ Executando

Abra o PowerShell:

```powershell

```

